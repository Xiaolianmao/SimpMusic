# SimpMusic 浏览器登录导入扩展

这是 SimpMusic 中文版的**可选本地扩展**，用于在用户明确操作后，将当前浏览器配置中的 YouTube（优兔音乐）或 Spotify（声田音乐）登录状态导入桌面端。

## 安装（首次一次）

1. 下载并解压 `browser-extension` 文件夹，里面应包含 `manifest.json`、`popup.html`、`popup.css`、`popup.js`。
2. 谷歌浏览器：打开 `chrome://extensions`。微软 Edge 浏览器：打开 `edge://extensions`。EGO 浏览器：使用其扩展管理页面（取决于具体版本）。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中 `browser-extension` 文件夹。
4. 建议将扩展固定在工具栏，之后无需重复安装。

EGO 浏览器是 Chromium（铬内核）浏览器，但各版本对扩展的支持可能不同。必须以实际版本的扩展管理界面与功能验证为准。

## 使用

1. 先在**同一个浏览器配置**中登录 YouTube 或 Spotify。
2. 在 SimpMusic 桌面端打开对应登录页面，点击“开始导入浏览器登录”。
3. 在 Chrome、Edge 或 EGO 的工具栏打开本扩展，输入 SimpMusic 显示的一次性验证码。
4. 点击“导入 YouTube”或“导入 Spotify”。完成后回到 SimpMusic 查看登录结果。

**验证码仅在本次导入中有效，约两分钟后失效。** 如有多个浏览器用户配置，请切换到实际已登录的配置，再点击扩展。

## 安全限制

- 无需账号密码，也不会绕过 Windows 的浏览器加密保护。
- 扩展只使用浏览器正式提供的 Cookie 访问权限，并且只读取当前选定的音乐服务。
- 只能向本机 `127.0.0.1:48518` 发送数据；不访问任何远程服务器。
- 本地接收服务只在用户启动导入后短暂运行，一次性验证码不能重复使用。
- 不会将登录信息写入仓库、日志、浏览器历史、网页地址或备份文件。
- 浏览器扩展权限较高，请仅使用来自自己仓库并亲自检查过的版本；不使用时可以将扩展停用。
- 登录状态本身相当于账号凭据，安装包和系统用户目录不要分享给别人。

## 0.2.0 兼容修复说明

- 修复某些 Chromium（铬内核）浏览器扩展请求不附带 Origin（来源标识）时，被桌面端错误拒绝的问题。
- 若浏览器弹出“访问本地网络/本机设备”授权请求，请在确认是本扩展后允许。
- 旧版扩展需要将本文件夹内四个扩展文件覆盖原位置，再打开 `chrome://extensions` 点击此扩展的“重新加载”。
- 桌面软件内的“一次性验证码”旁增加“复制验证码”按钮；原有验证码不可以反复使用，请每次重新点击“开始导入”。
- 本机 48518 端口仅在软件显示本次验证码期间开放；如果提示无法连接，请确认软件仍在等待，且运行的是最新版播放器。
- 即使修复连接失败，浏览器账号的实际有效性仍取决于服务端，不能保证登录成功。

## 已知限制

- 首次必须手动安装扩展，此过程无法被普通桌面应用安全地自动完成。
- 导入仅适用于当前浏览器配置中已经登录的账号；账号登录失效时需要重新登录。
- YouTube、Spotify 或浏览器今后调整会话策略时，可能影响导入功能。
- Windows 端、新版本 Edge、Chrome 与 EGO 的实际登录效果仍须进行应用安装包的端到端测试。
- 如果本地端口 `48518` 被其他应用占用，请关闭占用端口的应用后重试。
